# Swarm LLM 图组 · 风格方案

- 风格名：机房蓝图（Server-room Blueprint）
- 关键词：蓝图、走线、琥珀标记
- 描述：深海军蓝底模拟机房夜色与图纸感；青色(#5CA8FF/#38BDF8)走线与边框表达数据流与系统边界；琥珀色(#F5B14C)仅用于标记"系统心脏"与关键钩子，全图不超过三处，保证视觉重心唯一。信息高密度、模块芯片化，工程文档气质。
- 字体：标题/层级名=得意黑（展示感）；正文/芯片=MiSans；不换用衬线，保持工程感。
- 配色：背景 #0A1930；层带 #122A4E/#10263F/#16233B（逐层降温表示"可替换性递增"）；文字主 #FFFFFF，次 #9DB8DD，弱 #5E7BA3；心跳琥珀 #F5B14C。
- 版式：16:9 横版（1280×720），自上而下单向分层流，右侧注解列对齐三条"外包政策"，底部异构节点层落地。
- 核心元素：三层带 + 模块芯片 + 层间双向箭头（决策下行/遥测上行）+ 右侧政策注解 + 底部四类杂牌节点。
